# 🏫 Sri Bharathi EM School - Management Portal & Website

A modern, full-stack school management system and public web portal tailored for **Sri Bharathi English Medium School, Nagasamudram** (Nursery to 6th Class).

---

## ✨ Key Features

- **🌐 Public Web Portal:** Dynamic home showcase, facilities, school vision, admission enquiry desk, and public notice announcements.
- **🛡️ Role-Based Access Control:** Dual access controls for Administrator (full admissions & edit privileges) and Teachers (attendance & report cards).
- **👥 Student Directory:** Complete student records tracking with roll numbers, parent contact info, and grade management.
- **📊 Excel Bulk Data Import:** Fast student onboarding using `.xlsx` / `.xls` spreadsheets via Multer & XLSX parser.
- **📅 Daily Attendance Management:** Class-wise student attendance tracker with toggle indicators.
- **📲 Instant WhatsApp Absent & Fee Reminders:** One-click WhatsApp message triggers directly to parent phone numbers for fee dues and absenteeism alerts.
- **📄 Printable PDF Progress Reports:** Instant generation of student report cards with subject-wise marks distribution using `jspdf` and `html2canvas`.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5 Canvas, Modern CSS / Tailwind styles, Axios
- **Backend:** Node.js, Express.js, Multer
- **Database:** MongoDB Atlas (Cloud Database)
- **Reporting & Tools:** jsPDF, html2canvas, XLSX
